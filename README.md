# Kanboard AI Beta

Отдельный beta-плагин для Kanboard: создание задач из JSON, скопированного из веб-чата Qwen без API-ключа и без автоматического входа в Qwen.

## Установка

Скопируйте каталог `plugins/QwenTasks` в корень Kanboard:

```text
plugins/QwenTasks
```

Затем включите плагин в **Settings → Plugins**.

## Использование

1. Откройте Qwen в отдельной вкладке.
2. Попросите вернуть задачи в JSON.
3. В Kanboard откройте **Qwen Tasks**.
4. Выберите проект и вставьте JSON.
5. Подтвердите создание задач.

Пример:

```json
{
  "tasks": [
    {
      "title": "Подготовить релиз",
      "description": "Проверить чек-лист релиза",
      "tags": ["release", "beta"]
    }
  ]
}
```

Плагин проверяет права пользователя на проект и колонку, ограничивает импорт 50 задачами и использует штатную модель создания задач Kanboard.
